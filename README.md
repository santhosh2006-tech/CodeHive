# Service Catalog Documentation\n\n## Introduction\nThis is a service catalog that provides a central registry for services and infras. It allows users to register, update, and delete services and infras.\n\n## Services\nServices are registered with a name, host, and port. They can be updated and deleted.\n\n## Infras\nInfras are registered with a name, host, and port. They can be updated and deleted.\n\n## API Gateway\nThe API gateway provides endpoints for registering, updating, and deleting services and infras. It also provides endpoints for getting services and infras.\n\n## User Database\nThe user database stores information about users. It provides endpoints for creating, updating, and deleting users.\n\n## Service Registry\nThe service registry stores information about services. It provides endpoints for registering, updating, and deleting services.\n\n## Infra Registry\nThe infra registry stores information about infras. It provides endpoints for registering, updating, and deleting infras.
