# Introduction
This project provides a set of tests for the user database, service registry, API gateway, and infrastructure components.

# Test User DB
The test_user_db.py script tests the functionality of the user database, including getting a user by username.

# Test Service Registry
The test_service_registry.py script tests the functionality of the service registry, including registering and getting registered services.

# Test API Gateway
The test_api_gateway.py script tests the functionality of the API gateway, including routing requests to services.

# Test Infra
The test_infra.py script tests the functionality of the infrastructure, including creating resources.
