# Introduction
This project provides a set of tests for user database, service registry, API gateway, and infrastructure.

## Running Tests
To run the tests, execute the following commands:
```bash
python test_user_db.py
python test_service_registry.py
python test_api_gateway.py
python test_infra.py
```

## Test Coverage
The tests cover the following scenarios:
* User database: create user, get user
* Service registry: register service, get service
* API gateway: create API, get API
* Infrastructure: create infrastructure, get infrastructure
